# Statistics for ML
A practical statistics foundation for Machine Learning, AI Engineering, and ML Engineering.

- Mean / Median / IQR → understand and clean features
- Variance / Standard deviation → understand feature spread and scaling
- Distributions / Skewness → detect unusual feature behavior and choose transformations
- Probability → classification and probabilistic models
- Sampling / CLT → understand datasets and evaluation
- Confidence intervals → quantify uncertainty
- Hypothesis testing / p-values → A/B testing and comparing model performance
- Correlation → investigate relationships between features
- Normal distribution / Z-score → standardization and outlier analysis.
